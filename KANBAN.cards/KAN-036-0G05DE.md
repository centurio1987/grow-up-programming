# KAN-036-0G05DE — ds-guide-v2 전 편 전개 — 파일럿 3편의 골격·집필 안내를 자료구조 가이드 66편에 적용

## 전략
**쓰는 것.** 자료구조 **64 편**을 `sandbox/ds-guide-v2/SPEC.md` 골격으로 다시 쓴다. 활성 `.mdx` 66 에서 알고리즘 트랙 이관 대상 둘을 뺀 수다 — 그 둘은 「자료구조가 아니다」로 판정됐으므로 이 카드가 쓸 대상이 아니고 `.mdx` 를 걷는 것도 `KAN-039` 몫이다.

**선행은 없다. 이것이 이 카드의 첫째 전제다.** 2026-09-18 에 사용자가 이 카드의 사전 작업을 「공회전」으로 지적했고, 기준을 「이 카드 없이 목표의 어느 명령이 실패하는가」로 다시 대니 **백로그의 일곱이 하나도 안 걸렸다.** 가이드 게이트가 읽는 것은 다섯뿐이다 — 정본의 추출 구간 · 헤더의 연산 표 · 규약4 등급 · 직접 메모리 집합 · 축3 성장률. 전부 지금 서 있다(계약 67/69 · 정본 67/69).

**실증은 파일럿이 이미 냈다.** `KAN-035` 가 세 편(덱 · XOR 연결 리스트 · 적흑 트리)을 그 일곱 없이 썼고 검토 12 항목이 2026-09-14 전부 승인됐다. **형식이 증명된 상태에서 예순네 번 반복하는 일**이 이 카드다 — 새 규격을 세우는 일이 아니다.

**알고리즘 트랙이 답을 이미 보여 준다.** 그쪽은 111 편을 냈는데 그때 앞에 있던 것은 문제 문서와 테스트 케이스뿐이었다 — 구현조차 스텁이었고 **가이드 집필이 구현을 함께 낳았다.** 자료구조는 그보다 전제가 더 갖춰져 있다(정본 · 계약 스위트 · 4축 판정이 이미 선다). 더 준비할 것을 찾는 것이 아니라 **쓰기 시작하는 것**이 남은 일이다.

**순서는 쉬운 것부터 계열로 묶는다.** 등급이 `basic` 인 열다섯이 서술이 가장 짧고, 같은 계열(힙 아홉 · 정렬 집합 · 트라이)은 연산과 불변식이 비슷해 한 배치에서 리듬이 붙는다. 파일럿 셋이 이미 선형 둘과 트리 하나를 덮었으므로 **선형부터 시작해 그 셋을 본으로 삼는다.**

**한 편이 끝나면 한 편이 선다.** 배치가 끝날 때마다 그만큼의 `.mdx` 가 `.md` 로 바뀌고 게이트가 그것을 판정한다 — 중간 산출이 없는 카드가 아니다. 진행은 **남은 `.mdx` 수**로 잰다.

**마지막에 v1 장치를 걷는다.** 옛 리듬 검사는 `.mdx` 가 0 이 되면 종료코드 2 로 CI 를 멈추므로 **마지막 편과 같은 커밋에서** 걷어야 한다(파일럿 인계 ①). 옛 8 단계 골격 자산(`.claude/authoring/specs/ds-guide/` · 골격 시험의 면제 목록)도 그때 함께 간다.

**하지 않는 것.** 계약 층을 고치지 않는다 — 가이드가 정본을 **추출**할 뿐이고 정본이 틀렸으면 그것은 다른 카드의 일이다. 가이드를 쓰다 계약의 결함을 보면 **적어 두고 계속 쓴다**(고치러 가면 또 공회전이다). 새 선행 카드를 만들지 않는다.

### 단계별 완료 기준

- **`S1`~`S6`**: 그 묶음의 `.mdx` 가 전부 `-guide.md` 로 서고 `bun run tools/ci.ts all` 이 통과한다. 편마다 `check-v2`(P1~P20) · `check-proof --require` · `guide-core` 를 지난다. 옛 `.mdx` 는 그 구조의 `_deprecated/` 로 내린다(파일럿 셋이 그렇게 했다). **한 배치는 3~4 편**이고 배치마다 커밋한다 — 중간에 멈춰도 그만큼이 남는다.
- **`S7`**: 자료구조의 활성 `.mdx` 가 0 이고, 옛 리듬 검사와 그 기준선 · 옛 8 단계 명세 · 골격 시험의 면제 목록을 **마지막 편과 같은 커밋에서** 걷는다(먼저 걷으면 CI 가 멈춘다). `tools/ord004-manifest.json` 의 옛 경로도 그때 정리한다.

### 묶음 안에서 지키는 것

- **파일럿 셋을 본으로 삼는다** — 덱 · XOR 연결 리스트 · 적흑 트리. 새 형식을 발명하지 않는다.
- **정본이 없는 하나**(동시성 건너뛰기 목록)는 `deep.walk.final` 이 Rust 추출이다 — 규격 자리만 있고 이 카드가 세운다(파일럿 인계 ③).
- **메모리 동기 다섯**(비트 배열 · 블룸 필터 · 카운트민 스케치 · 뻐꾸기 필터 · 하이퍼로그로그)은 직접 메모리 집합 편입을 판정한다(인계 ④).
- 계약의 결함을 보면 **적어 두고 계속 쓴다.** 고치러 가지 않는다.

## 검증
- **진행은 남은 `.mdx` 수로 잰다.** 배치가 끝날 때마다 그 수가 줄고, 0 이 되면 이 카드가 끝난다(이관 대상 둘은 세지 않는다 — `KAN-039` 몫이다).
- **편마다 게이트를 지난다**: `bun run tools/check-v2.ts --all`(P1~P20) · `bun run tools/check-proof.ts --all` · `bun run tools/guide-core.ts check` · `bun run tools/build-html.ts --all`.
- **배치마다 `bun run tools/ci.ts all` 17 단계**가 통과한다.
- **옛 `.mdx` 는 지우지 않고 `_deprecated/` 로 내린다** — 시뮬 걸음을 옮기는 재료이고 파일럿 셋이 그렇게 했다.
- **계약 층을 안 고쳤다는 것**을 배치마다 확인한다(`git diff --name-only` 에 `.contract.ts` · `_reference/` · `<name>.ts` 가 없다. 다만 정본의 추출 구간 주석은 예외이고 그때는 사유를 적는다).
- **마지막 배치에서만** v1 장치를 걷고, 걷은 뒤 `ci.ts all` 이 통과한다(먼저 걷으면 종료코드 2 로 멈춘다).
- 새 선행 카드를 만들지 않았다. 계약 결함을 봤으면 **적어 둔 목록**이 남는다.
