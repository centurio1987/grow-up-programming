# KAN-045-D2PK6T — 인용 표류 게이트 — 병합으로 밀린 `경로:줄` 인용을 기계가 잡는다

## 전략
**푸는 것.** 문서·코드의 `경로:줄` 인용이 **병합·재발행으로 밀려 엉뚱한 줄을 가리키는 것**을 기계가 잡는다. 지금 게이트(`tools/check-citations.ts`)는 그 줄이 **실재하고 비어 있지 않은지**만 본다 — 밀린 인용은 내용이 있는 남의 줄을 가리키며 통과한다.

**왜 지금.** KAN-026 · KAN-027 재작업에서 같은 사고가 **세 번** 났고 세 번 다 사람(검토자)이 손으로 찾았다. 밀림은 병합할 때마다 생기고, 가이드 66편을 쓰는 KAN-036 은 인용을 대량으로 건다.

**설계 후보 넷과 고른 것.**

| 후보 | 방식 | 대가 |
|---|---|---|
| (가) 앵커 지문 | 인용 옆에 대상 줄의 짧은 지문을 함께 적는 규약 | 인용 1,137 건을 전부 고쳐야 한다 · 문체가 바뀐다 |
| (나) git 기준 대조 | 기준 커밋과 작업 트리를 비교해 「그 줄이 가리키던 내용이 지금 같은 번호에 있는가」 | 기준을 무엇으로 잡을지 CI 에서 애매하다 · 커밋 뒤에는 무력 |
| (다) 줄 인용 폐지 | 절 제목 · 기호 인용으로 바꾼다 | 대량 개정 · 줄 인용이 주는 정확도를 잃는다 |
| **(라) 대장(baseline)** | 인용마다 **대상 줄의 지문 해시**를 `tools/_baseline/citations.tsv` 에 적어 두고 게이트가 대조. 바뀌면 도구가 diff 를 내고 `--update` 로 갱신한다 | 대장 파일 하나가 늘고, 정당한 이동에도 갱신 커밋이 붙는다 |

**(라)를 고른다.** 저장소에 기준이 남아 CI 에서도 돌고(그 점이 (나)와 갈린다), 초기 대장은 도구가 한 번에 만든다. 선례도 있다 — `tools/_baseline/guide-rhythm.tsv`.

**규격의 핵심 셋.**
1. **지문은 내용이지 번호가 아니다.** 대상 줄의 공백 정규화 문자열의 해시를 적는다. 줄이 밀리면 번호는 같고 지문이 달라져 걸린다. 줄 내용이 정당하게 바뀌면 같은 자리에서 걸리고, 그때는 사람이 보고 `--update`.
2. **경로 없는 인용도 본다.** `` `:1234` `` 꼴은 같은 줄 앞의 경로, 없으면 그 파일 자신을 대상으로 푼다 — 지금 정규식은 확장자 있는 경로만 보아 이 꼴이 통째로 검사 밖이다(KAN-026 셋째 반려의 자리).
3. **기록은 예외다.** 배치 문서 · 카드 수행 내역처럼 「그때 그랬다」를 적는 자리는 대장에 넣지 않는다. 예외 목록을 도구 안에 두고 그 사유를 함께 적는다.

**하지 않는 것.** 이미 밀려 있는 인용을 전수로 고치는 일은 이 카드가 하지 않는다 — 도구가 목록을 내면 그 목록을 별도 작업으로 넘긴다(대장에는 「지금 상태」를 담되 밀린 것으로 판정된 자리는 표시해 둔다).

## 검증
**카드 종료 조건.**

1. `bun run tools/check-citations.ts` 가 **표류를 잡는다** — 자기시험 변형 셋에서 실패하고 정상 상태에서 통과한다.
2. `tools/_baseline/citations.tsv` 가 저장소에 있고 `--update` 로만 바뀐다. 그 `--update` 는 **존재 검사 실패와 보류 래칫 상승 둘 다에서** 아무것도 쓰지 않고 1 로 끝낸다.
3. `bun run tools/ci.ts all` 통과 · `bun test tools/check-citations.test.ts tools/ci-workflow.test.ts` 통과 · `cd rust && cargo test` 통과.
4. 지금 밀려 있는 인용의 목록이 배치 문서에 남고, 그 정정은 별도 작업으로 넘어간 것이 카드에 적힌다.

**39건을 잡은 것은 새 게이트가 아니라 `S3` 의 blame 대조다.** 대장은 인용이 이미 밀린 **뒤인** `S3` 에서 처음 생겼으므로(`S1` · `S2` 태그에는 대장 파일이 없다), 지금 밀려 있는 39건에 대해 `check` 는 exit 0 이다. 검증 실행 결과에 적었던 「새 게이트가 그것을 잡았습니다」는 사실이 아니다 — 대장이 `S1` 에 있었다면 게이트가 잡았을 자리이고, 게이트가 실제로 지키는 것은 **앞으로 생기는 밀림**이다. 39건의 정정은 KAN-046 이 한다.
