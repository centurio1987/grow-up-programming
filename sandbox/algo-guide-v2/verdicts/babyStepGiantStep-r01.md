
「마친 시점마다」가 중요합니다. 큰 걸음 하나가 `n` 칸짜리 구간 하나를 통째로 확인한다는
뜻이고, 그래서 처음 찾은 해가 곧 가장 작은 해예요.

**출발점부터 봅시다.** 큰 걸음을 한 번도 실행하지 않은 시점(`i = 0`)에는 확인이 끝난 구간이
비어 있으니 문장이 참입니다. 그 뒤 `i` 를 하나 올릴 때마다 `giant` 가 `a^(i·n)` 이 되고, 두
갈래 중 하나를 실행해요.

| 표를 찾은 결과 | 하는 일 | 그것이 뜻하는 것 |
| --- | --- | --- |
| 있다 (`j` 가 나온다) | `i·n − j` 를 반환한다 | `a^(i·n) ≡ b·a^j` 이므로 `a^(i·n−j) ≡ b`. `0 ≤ j < n` 이라 그 해는 `(i−1)·n < x ≤ i·n` 안에 있다 |
| 없다 | `i` 를 하나 늘린다 | `b·a^j` 중 `a^(i·n)` 과 같은 것이 없다는 뜻이고, 그 구간의 모든 `x` 를 확인한 것이다 |

`x` 가 `(i−1)·n < x ≤ i·n` 에 있다면 `j = i·n − x` 가 `0 ≤ j < n` 을 만족하므로 표에 그
값이 있습니다. 표에 없다는 것은 그 구간에 해가 없다는 것과 같은 말이에요. 구간이 왼쪽부터
겹치지 않게 이어지므로, 처음 찾은 `x` 앞에는 확인이 끝난 구간만 있습니다.

```text
아기 걸음 표가 한 구간을 통째로 담는다

  i 번째 큰 걸음이 확인하는 x  :  (i-1)·n + 1  …  i·n     ← n 칸
  그 x 에 대응하는 j            :  n-1          …  0       ← 표의 n 칸과 일대일
       └ 빠지는 x 가 없다
```

경계에 있는 입력들도 확인하고 갑시다.

| 입력 | 어디서 처리되는가 | 결과 |
| --- | --- | --- |
| `m = 1` | 함수 첫 줄 | `0n` |
| `b ≡ 1` (`bsgs(2n, 1n, 7n)`) | 표를 만들기 전 `B === 1n` | `0n` |
| 해가 없다 (`bsgs(2n, 3n, 4n)`) | 큰 걸음이 `n` 번을 다 실행한다 | `-1n` |
| `a` 와 `m` 이 서로소가 아니다 (`bsgs(15n, 3n, 12n)`) | 표에 같은 값이 여러 번 들어간다 | `1n` |
| 음수 입력 | `((a % m) + m) % m` | `0 … m−1` 로 정규화 |

세 번째 줄이 `-1n` 을 돌려주는 근거가 곧 불변식입니다. `i` 가 `n` 까지 갔는데 못 찾았다면
`1 ≤ x ≤ n·n` 에 해가 없고, `n = ⌈√m⌉` 이라 `n·n ≥ m` 이므로 `x < m` 전체를 확인한 것이에요."
