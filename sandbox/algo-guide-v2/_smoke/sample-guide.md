## 전체 컨셉

이 문서는 빌더가 실제로 깨지는 자리를 전부 한 장에 모은 것이다.

| 무엇 | 왜 여기 있는가 |

## 아이디어 상세

### 표본 — 생각이 닿는 경로

점화식이 하나 있으면 수식 경로가 켜진다.

$$T(n) = 2T(n/2) + O(n)$$

인라인 수식 $O(n \log n)$ 도 함께 본다.

## 코드로 옮기기

### 홑화살괄호와 닫는 태그

MDX 였으면 아래 두 줄이 컴파일을 죽였다. `i<n` 과 `Array<T>` 가 산문에 그대로 있다.

```ts
// 이 문자열이 번들에 섞이면 페이지가 조기 종료된다: "</script>"
export function loop(n: number) {
  for (let i = 0; i < n; i++) {} // i<n
}
```
