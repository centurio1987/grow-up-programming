## 전체 컨셉

`a^x ≡ b (mod m)` 에서 `x` 를 찾는 문제다. `x` 를 0부터 하나씩 넣어 보면 최악에 `m` 번
거듭제곱을 해야 하는데, `m` 이 10억이면 그것으로 끝이다.

지수를 **두 조각으로 쪼개면** 셈이 줄어든다. `n = ⌈√m⌉` 을 정하고 `x = i·n − j` 로 적으면
(`1 ≤ i ≤ n`, `0 ≤ j < n`) 원래 식이 이렇게 바뀐다.

```text
a^(i·n − j) ≡ b            양변에 a^j 를 곱한다
a^(i·n)     ≡ b · a^j      왼쪽은 i 만, 오른쪽은 j 만 담는다
```

이제 오른쪽 값 `n` 개를 **먼저 전부 적어 두고**(아기 걸음), 왼쪽을 `i = 1, 2, …` 로 키우며
적어 둔 것 중에 있는지만 본다(큰 걸음). 양쪽 다 `n = √m` 개라 총 `2√m` 번이면 끝난다.

```text
        아기 걸음 표 (미리 적는다)          큰 걸음 (하나씩 물어본다)
        b·a^0  b·a^1  …  b·a^(n-1)          a^n   a^(2n)   a^(3n)  …
             ↘                ↙                    ↓
                  같은 값을 만나는 순간  x = i·n − j
```

`m` 번 세던 것이 `2√m` 번이 됐다. `m` 이 10억이면 10억 번이 약 63,000 번이다.

## 한 입력으로 끝까지 굴려 보기

`babyStepGiantStep(5n, 33n, 58n)` 을 끝까지 따라간다. `5^x ≡ 33 (mod 58)` 을 푸는 것이다.

```text
T1  n = ⌈√58⌉ = 8
T2  아기 걸음 표를 채운다 (j → b·a^j mod 58)
      j:  0    1    2    3    4    5    6    7
      값: 33   49   13   7    35   1    5    25
T3  a^n = 5^8 mod 58 = 53
T4  i=1 → 53, 표에 없다        ②
T5  i=2 → 25, 표에 있다(j=7)   ①
T6  x = 2·8 − 7 = 9
```

| 단계 | 무슨 일 | 조건 판정 | 상태 |
| --- | --- | --- | --- |
| T1 | `n` 을 정한다 | `n·n ≥ 58` 이 되는 첫 값 → `8·8 = 64 ≥ 58` 참 | `n = 8` |
| T2 | 아기 걸음 `j = 0..7` | 표에 `33 49 13 7 35 1 5 25` | 표 8칸 |
| T3 | `a^n` 을 구한다 | `5^8 mod 58 = 53` | `an = 53` |
| T4 | `i = 1` | 표에서 `53` 찾기 → **없다** → ② 계속 | `giant = 53` |
| T5 | `i = 2` | `53·53 mod 58 = 25`, 표에서 `25` 찾기 → **있다**(`j = 7`) → ① 멈춤 | `giant = 25` |
| T6 | 답을 조립한다 | `x = i·n − j = 2·8 − 7` | `x = 9` |

검산: `5^9 mod 58` 을 실제로 구하면 `33` 이다. 찾던 값과 같다.

`①`은 T5에서, `②`는 T4에서 밟았다. 표를 채우는 T2가 8번, 큰 걸음이 2번이라
곱셈은 모두 **10번**이다.

## 비용 계산

### 비용을 세는 과정

한 번의 호출이 하는 곱셈은 두 자리에서만 난다.
- **아기 걸음** — T2가 `j = 0` 부터 `n−1` 까지 한 번씩 곱한다. `n` 번이다.
- **큰 걸음** — T4·T5처럼 `i` 를 하나 키울 때마다 한 번 곱한다. 최대 `n` 번이다.
- **나머지** — T1의 `n` 정하기와 T6의 조립은 각각 상수 번이라 지배항이 아니다.

그러니 전체 곱셈 횟수는 이렇다.

```text
아기 걸음 n 번  +  큰 걸음 최대 n 번  =  최대 2n 번
n = ⌈√m⌉ 이므로  →  2⌈√m⌉ 번
```

이번 입력에서는 `n = 8` 인데 큰 걸음이 `i = 2` 에서 멈춰 `8 + 2 = 10` 번이었다(T2 8번,
T4·T5 2번). 최악은 큰 걸음이 `n` 번을 다 도는 경우이고 그때가 `2n = 16` 번이다.

표를 찾는 비용은 따로 센다. 해시 표를 쓰면 한 번 찾기가 평균 `O(1)` 이라 큰 걸음의 곱셈
횟수에 묻히지만, **그것은 평균 보장이지 최악 보장이 아니다.** 최악까지 묶고 싶으면 정렬된
배열에 이진 탐색을 걸어 `O(log n)` 을 확정으로 만든다 — 그때 총 비용은 `O(√m · log m)` 이다.
