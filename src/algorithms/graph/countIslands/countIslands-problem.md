# Count Islands (섬 개수 세기)

## 한 줄 요약

> 함수는 `0`(물)과 `1`(땅)으로 채워진 2차원 격자를 받아, 상하좌우로 이어진 땅 덩어리(섬)의 개수를 반환한다.

## 스토리

해양 관측소의 연구원 민재는 위성이 찍은 바다 사진을 격자로 변환해 분석한다. 사진은 같은 크기의 정사각형 칸들로 잘려 직사각형 판을 이루고, 각 칸은 그 지점이 **땅이면 `1`, 바다면 `0`** 으로 기록된다.

민재가 세고 싶은 것은 사진 속 **섬의 개수**다. 한 섬은 서로 **맞닿아 이어진 땅 칸들의 덩어리**이다. 여기서 "맞닿았다"는 것은 칸의 **상·하·좌·우로 바로 인접**한 경우만 말한다. 모서리에서 대각선으로만 닿아 있는 두 땅 칸은 같은 섬이 아니다.

민재는 이 사진 한 장에 섬이 몇 개나 있는지 숫자 하나로 알고 싶어 한다.

## 함수 인터페이스

```ts
export function countIslands(grid: number[][]): number;
```

- `grid` — 2차원 격자. `grid[r][c]`는 `r`행 `c`열 칸의 값으로, `1`이면 땅, `0`이면 물
- 반환 — 격자에 있는 섬(상하좌우로 연결된 땅 덩어리)의 개수

## 제약 조건

- `grid`는 **직사각형** 격자이다. 즉 모든 행의 길이가 같다. 행 수를 $R$, 열 수를 $C$라 하면 모든 `grid[r]`의 길이는 $C$
- $0 \leq R \leq 10^{3}$, $0 \leq C \leq 10^{3}$, 그리고 $R \times C \leq 10^{6}$
- 각 칸의 값은 정수 `0` 또는 `1`만 가진다
- 연결은 **상하좌우 4방향**만 인정한다(대각선 제외)
- 입력은 항상 위 조건을 만족하는 **유효한 직사각형 0/1 격자**로만 주어진다(행 길이가 제각각인 jagged 배열이나 `null` 등 비정상 입력은 고려하지 않는다)
- `grid`와 그 내부 행 배열(`grid[r]`)을 **모두 변형하지 않는다** — 방문 표시를 위한 임시 수정도 하지 않고 입력을 원래 상태 그대로 보존한다
- 시간 제한: 1초, 메모리 제한: 256 MB

## 문제 상세

격자에서 **섬(island)** 의 개수를 센다. 섬이란 값이 `1`인 칸들이 상하좌우 인접으로 서로 연결되어 이루는 하나의 덩어리이다.

- 두 칸이 **인접**하다는 것은 한 변을 공유한다는 뜻이다(상·하·좌·우). 모서리(대각선)만 맞댄 칸은 인접이 아니다.
- 두 땅 칸이 **같은 섬**이라는 것은, 상하좌우 인접 이동만으로 한 칸에서 다른 칸까지 갈 수 있다는 뜻이다(중간 칸들도 모두 땅이어야 한다).
- 대각선으로만 닿은 두 땅 칸은 **서로 다른 섬**이다.
- 물 칸(`0`)은 어떤 섬에도 속하지 않는다.

경계 동작:

- 격자에 행이 하나도 없으면(`grid = []`) 섬은 `0`개이다.
- 행은 있으나 열이 없으면(예: `grid = [[]]`, 즉 $C = 0$) 섬은 `0`개이다.
- 모든 칸이 물이면 `0`, 격자 전체가 하나로 이어진 땅이면 `1`이다.
- 한 칸짜리 격자는 그 칸이 땅이면 `1`, 물이면 `0`이다.

## 예시

```ts
// 왼쪽 위 L자 덩어리 1개 + 오른쪽 아래 낱개 1개 = 2섬.
countIslands([
  [1, 1, 0],
  [0, 1, 0],
  [0, 0, 1],
]); // 2

// 5개의 땅이 서로 대각선으로만 닿아 전부 분리 = 5섬.
countIslands([
  [1, 0, 1],
  [0, 1, 0],
  [1, 0, 1],
]); // 5

// 전부 땅 — 하나로 이어짐 = 1섬.
countIslands([
  [1, 1],
  [1, 1],
]); // 1

// 한 행에서 물로 갈라짐 = 2섬.
countIslands([[1, 0, 1, 1]]); // 2

// 대각선만 닿음 = 2섬.
countIslands([
  [1, 0],
  [0, 1],
]); // 2

// 전부 물 = 0섬.
countIslands([
  [0, 0],
  [0, 0],
]); // 0

// 빈 격자 = 0섬.
countIslands([]); // 0

// 행은 있으나 열이 없음(R>0, C=0) = 0섬.
countIslands([[]]); // 0

// 한 칸짜리 격자.
countIslands([[1]]); // 1
countIslands([[0]]); // 0
```
