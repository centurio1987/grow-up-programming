# 자료구조 가이드 캔버스 (ORD-003 템플릿)

자료구조 가이드의 골격이다. **문제에 대응하는 가이드가 아니라, 자료구조 그 자체에 대한
독립 가이드**로 작성한다(특정 문제의 입출력에 종속되지 않는다). `##`/`###` 헤딩의 문구와
순서는 고정이다. 모범 예시(필독): `src/data-structures/tree/bPlusTree/bPlusTree-guide.mdx`.

**이 캔버스를 쓸 대상인지 먼저 확인한다 (ORD-005).** 경로가 `src/data-structures/**`라도
**구성 절차에 최적성·정당성을 증명해야 하는 선택이 들어 있는 구조**는 알고리즘 캔버스(10단계)를
쓴다. 판별은 `SKILL.md`의 "캔버스 판별" 절을 따른다. 이 캔버스는 **불변식 유지가 본체인 구조**
(탐색/삽입/삭제가 규칙을 지키며 동작하는 것)를 위한 것이다.

**조건부 절 규칙**: 알고리즘 캔버스와 동일 — 해당 없으면 문서에서 절을 생략하고,
사유 한 줄을 품질 게이트 보고에 기록한다.

**다이어그램**: 이 템플릿에는 mermaid 다이어그램 단계가 없다. 필요하다고 판단되면 사용자
확인 후에만 추가하고, 추가 시 check-mermaid.ts 파서 검증을 통과시킨다.
