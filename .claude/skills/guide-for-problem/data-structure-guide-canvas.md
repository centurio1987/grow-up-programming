# 자료구조 가이드 캔버스 (ORD-006 8단계)

자료구조 가이드의 렌더 템플릿이다. **골격의 정본은 이 파일이 아니라
`.claude/authoring/specs/ds-guide/spec.json` 의 `sections[]` 이고**, 항목별 작성 방법은
같은 디렉터리의 `spec.md` 에 있다. 셋이 어긋나면 spec 이 이긴다 — 집필기가 읽는 것이 spec 이다.
규격의 근거는 `docs/ORD-006-conventions.md` §규약3 이다.

**문제에 대응하는 가이드가 아니라 자료구조 그 자체에 대한 독립 가이드**로 쓴다. `##`/`###`
헤딩의 문구와 순서는 고정이다.

**이 캔버스를 쓸 대상인지 먼저 확인한다.** 경로가 `src/data-structures/**` 라도 **구성 절차에
최적성·정당성을 증명해야 하는 선택이 들어 있는 구조**는 알고리즘 캔버스(10단계)를 쓴다.
판별은 `SKILL.md` 의 "캔버스 판별" 절을 따른다.

**조건부 절 규칙**: 해당 없으면 문서에서 절을 생략하고, 사유 한 줄을 품질 게이트 보고에 기록한다.

**다이어그램**: 이 템플릿에는 mermaid 단계가 없다. 필요하다고 판단되면 사용자 확인 후에만
추가하고, 추가 시 `check-mermaid.ts` 파서 검증을 통과시킨다.
