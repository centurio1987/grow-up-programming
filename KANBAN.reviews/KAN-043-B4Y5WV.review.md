**기준**

- **회귀 없음이 첫째다.** 선택 자리를 열기 전과 후에 계약 스위트 전부가 같은 판정을 내야 한다 — `bun run tools/ci.ts all` 17단계가 통과하고, 축3 판정 결과가 하나도 달라지지 않는다. 측정 경로가 바뀌지 않았다는 것을 코드 변경 범위로도 보인다.
- **검증 비용이 계측에 안 섞인다**: 측정 실행과 검증 실행이 다른 인스턴스의 다른 실행이라는 것이 코드로 서고, 선택 인자를 준 시나리오의 계측값이 안 준 때와 **같다**는 것을 수치로 고정한다.
- **값 검사가 실효가 있다**: 값을 틀리는 구현이 값 검사에서 걸리고 **성장률 판정은 통과**하는 것을 자기시험이 고정한다. 둘이 독립이라는 증거이고, 이것이 없으면 「값도 본다」가 빈말이다.
- **성장률 판정은 그대로다**: 값 검사를 붙인 시나리오의 성장률 비율이 붙이기 전과 같다.
- **붙일 자리 판정**: 기준이 적히고 목록의 각 행이 처분과 근거를 갖는다. 기준이 놓치는 것이 있으면 그 사실을 적는다.
- **게이트**: `bun run tools/check-contract.ts`(시나리오에 필드가 늘면 이 도구가 함께 움직인다) · `bun run tools/check-citations.ts`(대장 지문 일치 · 래칫 세 칸 유지) · `bunx tsc --noEmit` · 고친 파일의 `bunx --bun @biomejs/biome check` 경고 0 · `cd rust && cargo test --workspace`.
- **줄 수를 인용이 물고 있는 파일을 조심한다**: 하네스 자기시험은 줄 번호로 인용되므로(런북 불변 사실 106 · 215) 고칠 때 줄 수를 유지하거나, 못 지키면 표류를 확인하고 대장을 갱신한다.
