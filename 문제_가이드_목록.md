# 문제 가이드 목록 (중요도순)

프로젝트의 모든 가이드를 **중요도(★★★ 필수 → ★★ 빈출 → ★ 특정 분야·고급)** 순으로 정리한 인덱스입니다.
분류 기준은 [알고리즘 중요도 기준 문제 목록.md](./알고리즘%20중요도%20기준%20문제%20목록.md)를 따릅니다.

> **관리 규칙**: 이 문서는 사람이 중요도 구조를 유지하며 관리합니다. 전체 재생성은 금지되어 있고,
> `generate-guides-index.sh`는 구조 보존 모드로 동작해 **누락된 가이드만** 맨 아래
> "자동 추가 (분류 대기)" 절에 덧붙입니다. 새 항목은 알맞은 기법 줄로 수동 이동해 주세요.
> `(변형)`은 해당 기법의 변형·응용 구현, `(신규 템플릿)`은 ORD-003 템플릿 파일럿을 뜻합니다.
