착수 판단 시점에는 Chrome 확장이 안 붙어 미확인이었고, 배치를 닫은 뒤 유저가 **aside(Playwright)
연결을 열어 주어** 실제 창 폭에서 확인했다. `file://` 은 막혀 있어 `127.0.0.1:8791` 로 원고
HTML 을 띄우고 열었다.

**대상**: `src/algorithms/number-theory/fftMultiply/fftMultiply-guide.html` · 창 1440×900

| 무엇 | 실측 |
| --- | --- |
| 레일 존재 | `nav.gs-rail` · `display: block` · `visibility: visible` · `opacity: 1` |
| 자리 | `position: fixed` · `x=1120` `w=208` → 오른쪽 끝 1328, 창 1440 |
| 항목 | **12** (`파트 1`~`스스로 점검하기`) |
| 끊어진 앵커 | **0** |
| 가로 넘침 | 없음 (`scrollWidth` 1440 = `innerWidth`) |
| 앵커 이동 | `#perf` 클릭 → `scrollY` 38,551 · 그 헤딩이 화면 위 24px |
| 현재 절 표시 | 이동 뒤 그 항목에 `is-here` 가 붙음 (한 개만) |

**배치4~7 연속으로 열려 있던 항목이 여기서 닫힌다.** 정적 확인(마크업·앵커·기준점)만으로는
「현재 절 표시가 실제로 따라오는가」를 못 봤는데, 그것이 이번에 처음 실측됐다.

**그리고 그 화면이 스캐너가 못 잡는 은유 하나를 보여 줬다** — 본문에 비용을 값으로 말한
형용사의 활용형이 실려 있었다. 전수 검색으로 **살아 있는 원고 10자리 · 6편**이 나왔고
`FEEDBACK.md` §4 「은유 계보 여덟째」에 목록째 적었다. **고치지 않았다** — 규칙을 넓히는 것과
원고를 고치는 것이 한 묶음이어야 하고 둘 다 `KAN-034.8` 몫이다.
