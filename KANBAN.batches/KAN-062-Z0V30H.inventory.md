## 1. 근거 목록 §5 의 처리

### 1-1. 셈 기준(§5-1)

| 항목 | 처리 | 결과 |

| 기하 7편의 「기본 연산」 구성이 편마다 다름 | 갈래 기본 구성(좌표 비교 · 방향 판정 · 곱셈 · 큰 정수 변환)으로 맞추거나, 다르게 세면 첫 문단에 구성을 적는다 | |

| 한 편 안에서 기준이 둘(gcd · digitDp · bridgesInGraph · segmentTreeRangeMin · knapsack01 · aStarSearch) | 둘 다 표의 이름으로 부르고 본문이 갈라 부른다. aStarSearch 는 이웃 목록 만들기를 넣었는지 내역에 적는다 | |
| 대조 절 산문의 배수 손 계산(46편 159곳 어림) | 증명 블록으로(SPEC §14 `L51`, P26) | |
