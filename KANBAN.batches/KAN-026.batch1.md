> 수행 방식은 **단일 에이전트 11 배치**로 결재됐다(2026-09-14). 배치 전체 표는 카드 문서 「전략 · 배치안」.

## 1. 작업 패키지

### WP1 · `S1` 17종 판정 + WBS 트랙 등록 — 코드 변경 없음

B19(`docs/ORD-006-runbook.md:1829`)처럼 **판정만** 하는 배치다. 구조 파일은 한 줄도 안 고친다.

| 순서 | 판정 | 입력 |
| --- | --- | --- |
| 1 | 17종 검증 등급 확정(basic · invariant · complexity) — 등급이 갈리면 계약도 갈린다 | `docs/ORD-006-p4-triage.md:32-51` · `docs/ORD-006-conventions.md:1764-1767` |
| 2 | 같은 계약 묶음 — `trie`=`ternarySearchTree`(B15) 적용 · `radixTree`↔`trie` · 리스트 셋 · 단조 둘 · 그래프 셋 | `conventions.md:1769-1794` |
| 3 | 공간 처분 — `bitArray` · `graphAdjMatrix`: 공간 제약을 관측하는 연산이 계약에 있는가 | `conventions.md:2258-2262,2863-2883` |
| 4 | 축밖 처분 — 확률 다섯(`bloomFilter`·`cuckooFilter`·`countMinSketch`·`hyperLogLog`·`minHash`)의 오차 보장을 계약이 어떻게 적는가. `cuckooFilter` 가 `bloomFilter` 와 같은 계약인지(갈리는 자리가 지우기) | `runbook.md:1872` · `conventions.md:2283-2285` |
| 5 | 메모리 직접 사용 목록 편입 — `bitArray`·`bloomFilter`·`countMinSketch`·`cuckooFilter`·`hyperLogLog`. typed array `byteLength` 로 절약을 보일 수 있으면 넣지 않는다 | `conventions.md:1400-1429` |
| 6 | 「자료구조인가」 — `rollingHash` · `dag` | `p4-triage.md:38-39` |

산출:
- 17종 처분표 → 카드 문서 「수행 내역」 한 줄 요약 + `docs/ORD-006-conventions.md` 새 절(절 추가만).
- `tools/ord006-wbs.ts` `UNITS` **파일 끝**에 A군 트랙 블록. 유닛 = 판정으로 접힌 계약 단위.
  기존 T1~T5 블록은 건드리지 않는다(`KAN-027` 이 같은 파일의 그 블록을 고친다).
- `docs/ORD-006-wbs.md` 트랙 표에 A군 행(대역 200–229).
- 런북 불변 사실 — 200번대부터.

**완료 기준**: `bun run tools/ord006-wbs.ts` 가 A군 트랙을 17종(접힌 만큼 유닛 수는 적을 수 있다)으로
내고(`cuckooFilter` 포함) · `bun run tools/ci.ts gates` 통과 · 처분표의 판정마다 근거 인용(`경로:줄`)이 붙어 있다.

## 2. 의존과 순서

- 1(등급) → 2(같은 계약): 등급이 다르면 계약이 다르다는 규칙이 2의 절반을 미리 닫는다.
- 3·4·5 는 서로 독립이지만 **5 는 4 뒤에** — 확률 구조의 계약이 선 뒤에야 「TS 에서 절약을
  보일 수 있는가」가 물을 대상을 갖는다.
- **배치 밖 의존 없음.** `cuckooFilter` 를 `bloomFilter` 와 함께 보라는 서술(`conventions.md:2285`)이
  `KAN-027` 과의 의존이었는데, 유저 결재로 이 카드에 이관해 풀었다.

## 3. 리스크

- **판정이 추정으로 흐르는 것.** 「메모리 직접 사용 목록」은 추정으로 올리지 않는다는 규칙이
  있다(`conventions.md:1429`). 판정마다 실행 가능한 근거(스위트 · `byteLength` 측정 가능성)가
  없으면 「미결 · 전환 work 에서 실측」으로 남긴다.
- **17종 한 배치가 세션 절반을 넘길 수 있다.** B19 는 11종이었다. 넘길 기미가 보이면 6(자료구조인가)을
  `S12`·`S11` 착수 시점으로 미룬다 — 두 구조의 판정은 다른 구조의 입력이 아니다.
- **병렬 카드와 공유 파일.** 이 배치가 쓰는 `conventions.md` · 런북 · `ord006-wbs.ts` 를 `KAN-027`
  배치1 도 쓴다. 번호 대역(200–229)과 「파일 끝에만 붙인다」로 충돌 면을 줄인다.
