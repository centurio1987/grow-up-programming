## 1. 작업 패키지

### WP1 · `S1` SPEC §14 「셈 기준과 용어」

근거 둘을 표로 옮긴다. KAN-058 전개 기록 §5(셈 기준 열 묶음 · 용어 열여섯 건), 그리고 bench 결과 파일 88개의 계수 이름 전수다. 전수 대조표는 `KANBAN.batches/KAN-062-Z0V30H.inventory.md` 에 두고 편마다 「표의 이름 · 지금 이름 · 고칠 곳」을 한 줄씩 적는다. SPEC 에는 결정만 적는다 — 셈 단위 어휘(시간·공간), 갈래별 「기본 연산」 정의 칸, 용어 열여섯 건의 선택과 이유, 대조 절 배수를 증명 블록에서 계산한다는 규칙.

**완료 기준**: SPEC §14 가 서고 §2 매핑 표와 §6 범위 원칙 표(L 규칙)에 새 규칙이 한 줄씩 걸린다 · 대조표에 §5 항목 전부와 bench 파일 88개가 빈칸 없이 있다 · `check-links`·`check-citations` 통과.

### WP2 · `S2` `check-v2` 규칙 둘

- bench 계수 이름이 §14 어휘 안에 있는가. 어휘 목록은 SPEC 을 다시 적지 않고 한 파일(`tools/cost-vocab.ts` 같은 자리)에 두고, SPEC 은 그 파일을 가리킨다(SPEC §10 「헬퍼는 저장소에 한 벌만 둔다」와 같은 방식).
- 「경쟁 설계와의 대조」 절에서 펜스 밖 산문이 `N 배` 꼴 측정 배수를 내밀면 위반. 증명 블록 안의 배수만 통과한다. 측정 배수가 아닌 「두 배로 늘린다」 같은 말을 어떻게 가를지는 자기시험 사례로 먼저 못 박는다.

**완료 기준**: `bun test tools` 에 두 규칙의 자기시험 통과 · 115편에 돌려 규칙마다 위반 수와 편 목록이 수행 내역에 적힌다(이 시점에는 실패가 정상이다).
